# Kinetic Gain Embedded — tie-back

## What this repo demonstrates

This repo demonstrates the **root-cause routing** primitive — downtime incidents tied to failure modes, restart blockers, and operator-safe escalation.

## How Kinetic Gain Embedded extends it

Kinetic Gain Embedded is security-first embedded analytics for B2B SaaS.
It extends this primitive to reliability-aware and restart-aware in-product analytics for industrial, maintenance, and operations workflows, wrapped in:

- signed JWT authentication
- semantic-layer row-level security (RLS)
- read-only data connectors
- AST SQL validation
- append-only audit events
